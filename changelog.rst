Changelog
=========

19.0.1.0.0
----------

* **Init**: Початковий реліз модуля `hr_hospital` для Odoo 19.0.
* **Models**:
  * Додано базову абстрактну модель `hr.hospital.medic.info` з обчисленням віку (`age`) та групою крові.
  * Реалізовано моделі `hr.hospital.doctor`, `hr.hospital.patient`, `hr.hospital.visit`.
  * Додано категорію лікарів та перевірку обмеження для менторів (`_check_mentor_not_intern`).
* **Security**:
  * Захист від редагування та видалення проведених візитів у методах `write` та `unlink`.
  * Налаштовано `ir.model.access.csv` для базових груп користувачів.
* **Tests**:
  * Додано юніт-тести для перевірки обчислення віку, валідації менторів та захисту візитів (`TransactionCase`).
* **UI/UX**:
  * Створено представлення (Form, List, Search) для лікарів, пацієнтів та візитів.
  * Додано кнопки швидких дій (Smart Buttons) в картку пацієнта.
