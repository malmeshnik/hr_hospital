=========================
Hospital Management System
=========================

Модуль призначення для автоматизації процесів обліку медичного закладу (клініки). Дозволяє ведення обліку лікарів, пацієнтів, історії захворювань та візитів.

.. contents::
   :local:

Key Features
============

* **Управління лікарями**:
  * Облік категорій лікарів та їх спеціалізацій.
  * Підтримка системи інтернатури та призначення менторів/наставників.
  * Автоматичне визначення статусу інтерна за допомогою обчислюваних полів.

* **Картка пацієнта**:
  * Збереження персональних даних, групи крові, статі та дати народження.
  * Автоматичний розрахунок віку пацієнта (`age`).
  * Зв'язок із призначеним лікарем та перегляд історії відвідувань.

* **Візити та безпека даних**:
  * Планування візитів пацієнтів до лікарів.
  * Фіксація діагнозів та опису візиту.
  * Захист від редагування (зміни лікаря/дати) та видалення проведених/завершених візитів.

* **Майстри (Wizards)**:
  * Швидке масове призначення або зміна лікаря для пацієнтів.
  * Формування звітів за обраний період.

Configuration
=============

1. Встановіть модуль через меню **Apps**.
2. Впевніться, що налаштовано базові довідники: Категорії лікарів, Захворювання.

Usage
=====

1. Перейдіть до меню **Hospital Management**.
2. Створіть записи лікарів та пацієнтів.
3. Фіксуйте візити через відповідний пункт меню або безпосередньо з картки пацієнта.
