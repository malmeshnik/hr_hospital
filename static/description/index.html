Hospital Management System

Комплексна система управління медичним закладом

Модуль hr_hospital призначений для автоматизації обліку лікарів, пацієнтів та медичних візитів у клініці.

Основні можливості модуля

Управління персоналом

  • Облік лікарів та їхніх категорій.
  • Підтримка системи наставництва (менторство для інтернів).
  • Автоматичне визначення статусу інтерна.

Картка пацієнта

  • Ведення персональних даних та медичної інформації (група крові, стать, вік).
  • Автоматичний розрахунок віку пацієнта.
  • Історія призначених лікарів та проведених візитів.

Управління візитами

  • Планування візитів до лікарів.
  • Фіксація діагнозів та історії хвороб.
  • Захист даних: заборона модифікації або видалення закритих візитів.

Зручні майстри (Wizards)

  • Майстер масового призначення лікаря пацієнтам.
  • Звіти про візити за обраний період.
  • Швидке перепланування візитів.

Технічні особливості

Модуль розроблений з використанням стандартних принципів розширення Odoo ORM, включає ізольовані юніт-тести та підтримує багатомовність (UA / EN).
